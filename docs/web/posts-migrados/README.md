# Posts migrados de la web anterior

Los 2 artículos de `next-chakraUI` (commit `d627669`), pasados de JSX a Markdown para crearlos como posts en el admin. Las imágenes ya las sirve `apps/web` en `/img/blog/`. Con estos slugs, las URLs de la web anterior (`/blog/arreglos` y `/blog/backend-api`) siguen funcionando.

| Archivo | Título | Slug | Extracto | Tags (propuestos) |
| --- | --- | --- | --- | --- |
| `arreglos.md` | Métodos de Array | `arreglos` | Si eres un programador backend o frontend en JavaScript o TypeScript, es muy usual trabajar con arreglos; aquí te invito a conocer algunos de sus métodos para que puedas manipularlos. | `javascript`, `typescript` |
| `backend-api.md` | Configurando un Backend con Express, MongoDB, Typescript y Docker | `backend-api` | Hola, amigo: este tutorial es para que puedas aprender a configurar tu backend con las tecnologías del stack MERN. | `express`, `mongodb`, `typescript`, `docker` |

## Qué cambió respecto al original

- **Texto:** solo ortografía y puntuación (acentos, «rebisaremos», «INGRDIENTES», «Configruracion», «siquientes», «libreias», «nusestro», «siguient», «nuetra basa», «entusisasma», «escriremos»). El código va idéntico, incluidos sus comentarios.
- **Formato:** cada método o paso es un `##`; los badges pasan a `código` en línea; los bloques de código llevan su lenguaje.
- **Imágenes:** con `alt` descriptivo (antes faltaba o decía «Debred»). La portada de los dos artículos es la misma imagen, como en la web anterior.
- **Fecha de publicación:** la web anterior no la tenía; al publicarlos en el admin tendrán la fecha de ese día.
